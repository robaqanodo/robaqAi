# R.AI — iPhone-ზე გაშვება

## რა არის მომზადებული

- React აპის ადგილობრივად შეფუთული Capacitor 8 iOS ვერსია; გასახსნელად Mac-ის სერვერი არ სჭირდება.
- iPhone-ის პორტრეტული რეჟიმი, Dynamic Island-ისა და Home Indicator-ის უსაფრთხო ზონები.
- კლავიატურის გამოჩენისას ჩატის ზომის ცვლილება; 44-პიქსელიანი ძირითადი შეხების ღილაკები.
- მშობლიური ხმოვანი შეყვანის ინტეგრაცია და მიკროფონის/მეტყველების ნებართვის ტექსტები.
- API მოთხოვნების მშობლიური HTTP ტრანსპორტი, ადგილობრივი ოფლაინ ცოდნის პაკეტები.
- მუქი საწყისი ეკრანი და R.AI-ის 1024×1024 აპის ხატულა.

ონლაინ პასუხებს სჭირდება ინტერნეტი და საკუთარი API გასაღები. გასაღები ამ ვერსიაში მოწყობილობის WebView-ის localStorage-ში ინახება (Keychain არ არის დანერგილი). Mac-ის ბრაუზერში შენახული გასაღები ტელეფონზე ავტომატურად არ გადადის.

## ამ Mac-ზე დარჩენილი ნაბიჯები

შემოწმებისას სრული Xcode და iPhone SDK არ იყო დაყენებული. ამის გამო native კომპილაცია, ხელმოწერა და ტელეფონზე დაყენება ჯერ არ შესრულებულა.

1. Mac App Store-იდან დააყენე **Xcode 26 ან უფრო ახალი**, რომელიც შენი iPhone-ის iOS ვერსიას უჭერს მხარს. პირველად გახსნისას დაასრულე საჭირო კომპონენტების დაყენება და აირჩიე iOS platform support.
2. Xcode → Settings → Locations → Command Line Tools-ში აირჩიე დაყენებული Xcode.
3. Xcode → Settings → Apple Accounts-ში თავად შედი შენი Apple Account-ით.
4. Terminal-ში გაუშვი:

   ```sh
   cd /Users/nodo.92/Desktop/WORK/R.AI
   npm run ios:check
   npm run ios:sync
   npm run ios:open
   ```

5. პროექტში აირჩიე **App target → Signing & Capabilities**. ჩართე Automatically manage signing და აირჩიე შენი Team. თუ Bundle Identifier დაკავებულია, შეცვალე `com.nodo92.rai` შენს უნიკალურ იდენტიფიკატორზე როგორც Xcode-ში, ისე `capacitor.config.ts`-ში.
6. USB-C კაბელით შეაერთე iPhone 17 Pro Max. ტელეფონზე თავად დაადასტურე Trust და, Xcode-ის მითითების შემთხვევაში, Settings → Privacy & Security → Developer Mode.
7. Xcode-ის გასაშვებ მოწყობილობად აირჩიე შენი iPhone და დააჭირე **Run ▶**. Swift Package Manager პირველ გაშვებაზე ჩამოტვირთავს native დამოკიდებულებებს.

App Store-ში გამოქვეყნება ამ სამუშაოს ნაწილი არ არის. აპი პირად iPhone-ზე ადგილობრივი გაშვებისთვისაა მომზადებული.

## შემდგომი ცვლილებები

ყველა კოდის ცვლილება შეინახე R.AI საქაღალდეში, შემდეგ გაუშვი `npm run ios:sync` და Xcode-ში ისევ Run. `ios/App/App/public` გენერირებული ასლია; იქ პირდაპირ ნუ შეცვლი კოდს — წყაროა `src` და `public`.

`npm run dev` კვლავ ხსნის ჩვეულებრივ ვებვერსიას. `npm test` ამოწმებს ხმოვანი შეყვანის JavaScript ადაპტერს. `npm run lint` ამოწმებს პროექტის კოდს.

პროექტის ფაილები და npm-ის ქეში ამ საქაღალდეშია. Xcode და Apple-ის ხელმოწერის სისტემური მონაცემები თვითონ macOS-ის/Xcode-ის მიერ იმართება.
